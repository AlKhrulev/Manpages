# Greek alphabet

| Lowercase | Uppercase | Name | Read as |
|---|---|---|---|
| α | Α | alpha | AL-fuh |
| β | Β | beta | BAY-tuh |
| γ | Γ | gamma | GAM-uh |
| δ | Δ | delta | DEL-tuh |
| ε | Ε | epsilon | EP-sih-lon |
| ζ | Ζ | zeta | ZAY-tuh |
| η | Η | eta | AY-tuh |
| θ | Θ | theta | THAY-tuh |
| ι | Ι | iota | eye-OH-tuh |
| κ | Κ | kappa | KAP-uh |
| λ | Λ | lambda | LAM-duh |
| μ | Μ | mu | MYOO |
| ν | Ν | nu | NOO |
| ξ | Ξ | xi | KSAI (also ZAI) |
| ο | Ο | omicron | OM-ih-kron |
| π | Π | pi | PIE |
| ρ | Ρ | rho | ROH |
| σ | Σ | sigma | SIG-muh |
| τ | Τ | tau | TOW (rhymes with “cow”) |
| υ | Υ | upsilon | UP-sih-lon |
| φ | Φ | phi | FIE (also FEE) |
| χ | Χ | chi | KAI (also KEE) |
| ψ | Ψ | psi | SAI (also SEE) |
| ω | Ω | omega | oh-MAY-guh |

At the end of a Greek word, lowercase sigma is written `ς` instead of `σ`; both are read “sigma.”
